# Gui's Tools

A little collection of learning tools made for Gui.

**Live site:** https://retrofootprints.github.io/guitools/

## Tools

- **24-Hour Clock** — a single-hand clock face that completes one full
  revolution every 24 hours, splitting day (07:00–19:00) and night
  (19:00–07:00) visually to help build intuition for hours.

## Development

Static HTML/CSS/JS, no build step. Serve locally with:

```
python -m http.server 8000
```

Then open http://localhost:8000/. Pushes to `main` deploy automatically
via GitHub Pages.
